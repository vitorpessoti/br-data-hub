# 003-api-brasilapi

## Objetivo

Entregar o fluxo completo de **enriquecimento de dados de CNPJ** com um módulo `cnpj` com busca na API da BrasilAPI e persistência de dados via Prisma.

## Contexto técnico

### Backend

- módulo `cnpj`
- acesso à API BrasilAPI (brasilapi.com.br)
- dados sempre em JSON
- persistência via prisma
- endpoint de recebimento de um CNPJ (a API precisa esperar receber tanto com formatação padrão de CNPJ quanto sem formatação - apenas alfanuméricos; deve tratar removendo a formatação caso venha formatado) no body que será usado para buscar os dados completos na BrasilAPI
- endpoint de busca na base de dados para retornar os dados existentes para aquele CNPJ
- endpoint de atualização dos dados na base via Prisma
- endpoint de exclusão dos dados da base via Prisma
- constantes de mensagens de erro definidas para insucesso na busca na API externa; para erros na persistência dos dados; para erros na busca de dados do CNPJ na base
